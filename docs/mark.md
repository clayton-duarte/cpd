# The cpd mark

cpd is written **φ** (U+03C6 GREEK SMALL LETTER PHI), as pi is written **π**. The word stays `cpd`; the mark sits beside the name wherever the name is introduced.

φ reads three ways at once:

- it overlaps the three letters **C·P·D**;
- it references the **golden ratio** (φ, 1.618…);
- it reads like a **dango**.

## Logo

The logo is **φ set in EB Garamond**, a free font. The runner-up fonts were **Vollkorn** and **Tektur**. The logo itself is defined soon; this page records the decision (hs-d694) until then.
