# The test files that keep exec tests of their OWN shell script, as a named exception to "no test spawns a process"
# (policy [tests]; docs/implementing.md, Tests; ADR 0013 "Stays"). One line per file: `<path> # <reason>`. The path
# exists, no file is listed twice, and cli/tests/tooling/smoke.rs (the assert_cmd smoke tests of the binary) is not
# listed: it is allowed by name. A file is listed only while its subject is a script that must exist before cpd does,
# or that cpd cannot be (a script that builds cpd); a test of cpd's own code is never listed: it runs in process.
cli/tests/tooling/cargo_script.rs # scripts/cargo.sh resolves cargo and sccache and exports RUSTC_WRAPPER; it builds cpd, so it cannot be a cpd subcommand. The cargo, sccache and cpd it runs are written by the test (no real ones)
cli/tests/tooling/npm_fresh.rs # scripts/npm-fresh.sh decides whether node_modules is fresh before cpd or the quick check run; sh, the files of a temp project and the node that reads them are the subject; the npm is written by the test
cli/tests/tooling/preview_script.rs # scripts/preview-tui.sh previews a build in the cockpit's views; a developer's shell script, not part of cpd
cli/tests/tooling/install_script.rs # the 10 tests of scripts/check-portable.sh, which guards the shell that stays; the install itself is `cpd install`, tested in process
cli/tests/tooling/tripwire_script.rs # scripts/tripwire/tmux, the stand-in the Gate puts first on PATH: bootstrap shell that must not need cpd (dies with the allowlist in the last PR)
cli/tests/tooling/gate_run_smoke.rs # scripts/gate-run.sh, the wrapper: sh exports GATE_RUN, runs the command and execs `cpd gate finish`; the leak check itself is tested in process
cli/tests/tooling/version.rs # the install-cpd.sh test: the bootstrap exports CPD_COMMIT=$(git rev-parse --short HEAD) to the cargo it runs, before any cpd exists; its other four tests run in process
core/tests/repin.rs # scripts/repin.sh resolves a schema-pin conflict in a git merge (git ls-files --unmerged, git add): a script, which the git route does not serve
core/tests/migrations.rs # scripts/check-migrations-frozen.sh and scripts/new-migration.sh (until `cpd tag` and `cpd version sync` take new-migration); the additive and order tests of the same file run in process
pi/test/pi-check.test.ts # scripts/pi-check.sh on a real pty: SIGTERM of pi and its children, the python3 pty runner (a kernel fact)
